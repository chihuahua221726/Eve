# Eve

All the holidays, but the number of days away is shown as that many "Eve"s.
For one day away, that's one Eve (e.g. "New Year's Eve").

## Usage

```bash
python main.py
python main.py --date 2026-12-01
```

See `eve_output.txt` for a generated example.
The web pages and generated SVG use its repeated Eve strings as their countdown content.

## Web app

Run the holiday countdown in a browser on localhost:

```bash
python web.py
```

Then open http://127.0.0.1:8000.
